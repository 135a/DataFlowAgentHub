## Why

当前前端模式下，用户只能通过一个不起眼的 checkbox 选择"深度分析"，两种模式的区别不直观，处理过程中没有进度反馈，用户体验差。需要将模式选择改为显式的按钮切换，并实时展示处理进度和时间预估，提升产品的专业感和可用性。

## What Changes

- 将消息输入框旁的 checkbox 替换为两个彩色按钮（快速查询 / 深度分析）
- 两种模式均展示步骤进度条面板，包含已完成/进行中/等待中状态
- 实时显示已用时间和预估剩余时间，首次写死，后续基于历史平均耗时推算
- 默认模式可保存（localStorage），用户可随时切换默认偏好
- 在输入框下方展示当前模式的描述说明和预估等待时间
- 所有功能纯前端实现，不涉及后端改动

## Capabilities

### New Capabilities
- `query-mode-ui`: 查询模式选择 UI，包含模式切换按钮、模式描述、进度面板、时间预估

### Modified Capabilities

无

## Impact

- `web/src/App.tsx`: 核心改动文件，替换 checkbox 为按钮组，新增进度面板组件
- 后端无改动
