## MODIFIED Requirements

### Requirement: 多 Agent 会话中间链路追踪（Trace）保存
扩展会话上下文历史的存储范围，要求不仅仅保存系统的最终回答，还需完整记录多个被激活子 Agent 的中间思考阶段与结果。

#### Scenario: 中间步骤的回放与前端呈现
- **WHEN** 用户尝试查询某次包含了多步协作的复杂任务（如“查数据->做分析”）的历史会话详情。
- **THEN** 后端接口返回的数据流必须结构化地包含每一个运行步骤（Run Steps），例如清晰区分“NL2SQL 提取完成 -> 分析 Agent 处理完毕 -> 报表已生成”，从而实现推理全过程的白盒化溯源展示。
