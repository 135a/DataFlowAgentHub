## 数据流概要

| 流向 | 协议 | 说明 |
|------|------|------|
| Browser → Go | HTTP/SSE | REST API + 实时事件推送 |
| Go → Python | gRPC (:50051) | NL2SQL 生成请求 |
| Python → Go | gRPC (:9090) | 任务回调、步骤追踪、内部 NL2SQL |
| Go → NATS | TCP | 异步任务发布 |
| NATS → Python | TCP | 异步任务消费 |
| Go → PG/Redis | TCP | 数据库操作、缓存、限流 |
| Python → ChromaDB | HTTP | 向量嵌入存储、语义搜索 |
| Python → OpenAI | HTTPS | LLM 调用（60s 超时） |
